Questions fréquentes

KermHosting est une plateforme d'hébergement de serveurs Node.js spécialement conçue pour les développeurs africains. Nous proposons des serveurs haute performance avec paiement en FCFA via Mobile Money (Orange Money, MTN Money).

Notre objectif est de rendre l'hébergement accessible à tous avec des tarifs adaptés et un support réactif.

Les coins sont notre monnaie virtuelle. Voici comment ça marche :

  • 1 coin = 5 FCFA
  • Vous pouvez acheter des packs de coins avec des réductions
  • Gagnez des coins chaque jour en vous connectant (5 coins/jour)
  • Parrainez des amis et gagnez 20 coins par filleul
  • Utilisez vos coins pour payer vos serveurs

Nous acceptons plusieurs moyens de paiement en FCFA :

  • Orange Money : Entrez votre numéro Orange Money, vous recevrez une demande de confirmation sur votre téléphone
  • MTN Money : Même principe, entrez votre numéro MTN et confirmez sur votre mobile
  • Cartes bancaires : Visa, Mastercard (via notre partenaire)

Le paiement est instantané et sécurisé via Fapshi.

Si votre paiement échoue, voici quelques étapes à suivre :

  1. Vérifiez que vous avez suffisamment de fonds sur votre compte Mobile Money
  2. Assurez-vous que votre numéro de téléphone est correct
  3. Attendez quelques minutes et réessayez
  4. Si le problème persiste, contactez notre support avec l'ID de la transaction

Aucun montant ne sera débité en cas d'échec.

Pour créer un serveur :

  1. Connectez-vous à votre compte
  2. Allez dans la section "Tarifs"
  3. Choisissez le plan qui vous convient
  4. Sélectionnez votre mode de paiement (coins ou Mobile Money)
  5. Choisissez un nom pour votre serveur (3-30 caractères)
  6. Choisissez un nom d'utilisateur (3-20 caractères, lettres/chiffres/_)
  7. Confirmez le paiement

Votre serveur sera créé en moins d'une minute !

Vos identifiants sont :

  • Envoyés par email immédiatement après la création
  • Affichés à l'écran juste après le paiement
  • Accessibles dans le tableau de bord en cliquant sur les détails du serveur

Le mot de passe commence toujours par Kh- (ex: Kh-a3f2).

Gestion de l'expiration :

  • 3 jours avant : Vous recevez un email d'avertissement
  • Jour J : Le serveur est arrêté mais pas supprimé
  • J+7 : Le serveur est définitivement supprimé si non renouvelé

Vous pouvez renouveler à tout moment depuis le tableau de bord.

Pour renouveler un serveur :

  1. Allez dans votre tableau de bord
  2. Cliquez sur les détails du serveur à renouveler
  3. Cliquez sur le bouton "Renouveler"
  4. Confirmez avec vos coins

Le renouvellement prolonge la durée de 30 jours.

Lors de votre inscription, un code de vérification à 6 chiffres vous est envoyé par email. Entrez ce code sur la page de vérification pour activer votre compte.

Si vous n'avez pas reçu le code :

  • Vérifiez vos spams
  • Attendez 2 minutes et cliquez sur "Renvoyer le code"
  • Vérifiez que l'adresse email est correcte

Pas de panique !

  1. Allez sur la page "Mot de passe oublié"
  2. Entrez votre adresse email
  3. Vous recevrez un code de réinitialisation à 6 chiffres
  4. Entrez ce code et choisissez un nouveau mot de passe

Le code expire après 15 minutes.

Notre système de parrainage :

  • Pour le parrain : 20 coins par filleul
  • Pour le filleul : 10 coins de bienvenue
  • Le filleul reçoit en plus 5 coins pour la vérification email
  • Total pour le filleul : 15 coins (10+5)

Votre lien de parrainage est disponible dans votre profil.

Pour acheter des coins :

  1. Allez dans la section "Acheter des coins"
  2. Choisissez un pack (Découverte, Populaire, Performance, Ultimate)
  3. Sélectionnez votre opérateur (MTN ou Orange)
  4. Entrez votre numéro de téléphone
  5. Confirmez le paiement sur votre mobile

Les packs offrent des bonus : plus vous achetez, plus vous économisez !

Oui, les coins peuvent être utilisés pour :

  • Créer de nouveaux serveurs
  • Renouveler des serveurs existants
  • Passer à un plan supérieur

1 coin = 5 FCFA d'économie par rapport au paiement direct.

Nous supportons les versions LTS de Node.js :

  • Node.js 18.x (LTS)
  • Node.js 20.x (LTS)
  • Node.js 22.x (latest)

Vous pouvez changer de version à tout moment depuis le panel.

  • Gestionnaire de fichiers web : Interface simple pour uploader et éditer
  • FTP/SFTP : Utilisez les identifiants FTP fournis
  • Git : Clonez directement votre dépôt sur le serveur

Le gestionnaire de fichiers supporte aussi l'édition en direct.
