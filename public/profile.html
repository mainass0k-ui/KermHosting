API KermHosting

Automatisez la gestion de vos serveurs Node.js grâce à notre API REST.

Votre clé API se trouve dans l'onglet Sécurité. Utilisez-la dans le header Authorization: Bearer VOTRE_TOKEN

GET /api/servers Liste des serveurs
POST /api/create-server Créer un serveur
GET /api/servers/{id}/stats Stats temps réel
POST /api/servers/{id}/command Commande console
POST /api/payment/buy-coins Acheter des coins
GET /api/referral/info Parrainage

Base URL : https://kermhosting.site/api

Authentification : Authorization: Bearer VOTRE_TOKEN

Token JWT : Valable 7 jours
