Installation en 4 étapes

1

Installer Node.js 20+

Téléchargez et installez Node.js version 20 ou supérieure depuis nodejs.org

node --version
2

Télécharger le bot

Téléchargez le fichier ZIP du bot et extrayez-le

unzip KERM-MD-V1.zip -d ~/kerm-md
3

Installer les dépendances

Installez toutes les dépendances nécessaires

cd ~/kerm-md && npm install
4

Lancer le bot

Démarrez le bot et scannez le QR code avec WhatsApp

npm start
